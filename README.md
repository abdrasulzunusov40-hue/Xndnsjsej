# Сайт ИП Кудайкулов Темирлан Кубанычович

Одностраничный сайт: услуги, цены, калькулятор, заявка через WhatsApp.

## Структура
```
index.html        главная страница
404.html          страница ошибки
favicon.svg       значок сайта
robots.txt        правила для поисковиков
.nojekyll         отключает Jekyll на GitHub Pages
css/style.css     стили
js/config.js      номер WhatsApp и почта
js/calc.js        калькулятор
js/form.js        форма заявки
```

## Как опубликовать на GitHub Pages
1. Создайте репозиторий на github.com (Public).
2. Загрузите всё содержимое папки в корень репозитория вместе с папками `css` и `js`.
3. Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save.
4. Через 1–2 минуты сайт откроется на `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`.
